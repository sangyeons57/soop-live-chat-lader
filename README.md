# SOOP Live Chat Lader

SOOP Live Chat Lader는 숲 실시간 방송에서 채팅이 너무 많이 올라오는 방송인을 대상으로, 채팅을 통계화해 현재 어떤 채팅이 발생하고 있는지 알려주는 Chrome 확장 프로그램입니다.

## 기본 구조

```text
.
├── manifest.json
├── sidepanel.html
├── assets/
│   └── logo.svg
└── src/
    ├── background.js
    ├── sidepanel.css
    └── sidepanel.js
```

## 포함된 화면

- Chrome Side Panel 화면
- 확장 프로그램 로고

## 제외된 화면

- Popup 화면
- 설정 페이지
